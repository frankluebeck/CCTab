GAP package CCTab

Author: Frank Lübeck
Needs: GAP in version at least 4.16;
  an installation of the FLINT library including header files;
  a C-compiler to compile a new kernel function and some standalone programs;
  GAPDoc in version at least 1.6 for accessing the documentation
Operating systems: Any, on which GAP is running. (For the provided kernel function the operating system needs to support dynamic loading of kernel code.) If the standalone programs using FLINT cannot be compiled the package will fall back on equivalent GAP functions.
Current version: 0.4 (released 08/10/2026)
Contact: Frank.Luebeck@Math.RWTH-Aachen.De
Download: See below for archives in several formats.
Metadata: PackageInfo.g.
History: This text file CHANGES describes the most important differences to former versions of the package.

Description

After loading this package GAP will use a different method to compute the character table of a non-solvable group. There is also the possibility to construct complicated character tables interactively.

Some functions of this package may be of independent interest: identification of conjugacy classes of given elements, computation of power maps, utilities for unimodular matrices.
